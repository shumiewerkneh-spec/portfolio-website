# 💼 Personal Portfolio Website

A modern, responsive, and user-friendly **personal portfolio website** built to showcase my skills, projects, experience, and continuous growth as a Software Engineering student and Frontend Developer.

## 🌐 Live Demo [https://werkneh-portfolio.netlify.app/]

🚀 **[View Portfolio Website](https://shumiewerkneh-spec.github.io/portfolio-website/)**

## 📌 About the Project

This portfolio website was created to present my development skills and projects in a clean and professional way.

It includes sections for:

* 👋 About Me
* 🛠️ Technical Skills
* 🚀 Projects
* 📚 Learning Journey
* 📩 Contact Information

The website is designed to provide a simple and professional experience for recruiters, developers, and potential clients.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shumiewerkneh-spec/portfolio-website.git
```

### 2. Open the project

```bash
cd portfolio-website
```

### 3. Run the website

Open `index.html` directly in your browser, or use **Live Server** in VS Code.
